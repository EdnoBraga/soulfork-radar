Como criar a chave (5–10 minutos, uma vez só)
  1. Acesse console.cloud.google.com e entre com sua conta Google
  2. Crie um projeto (qualquer nome, ex.: radar)
  3. No menu, vá em APIs e serviços → Biblioteca, procure Places API (New) e clique em Ativar
  4. Ative o faturamento do projeto (pede cartão; o crédito gratuito mensal cobre o uso normal antes de qualquer cobrança)
  5. Em APIs e serviços → Credenciais, clique Criar credenciais → Chave de API
  6. Copie a chave (começa com AIza) e cole aqui em cima

Dica de segurança: em "Restrições de API" da chave, restrinja à Places API (New). Não use restrição por site/referer — o Radar chama do seu computador, não de um site.
